# GOLD_HUD_Controls

Generic HUD + hotkey controller demo stack.

Uses:
- DemonHUD
- DemonHotkeys

## Run
- `stacks/GOLD_HUD_Controls/gold_hud_controls.ahk`

## Hotkeys
- Ctrl+Alt+H — toggle HUD
- Ctrl+Alt+U — toggle HUD heartbeat
- Ctrl+Alt+T — toggle worker tick
- Ctrl+Alt+Up/Down — opacity +/- 10
- Ctrl+Alt+Left/Right/PgUp/PgDn — move HUD
- Ctrl+Alt+L — marker
- Esc — exit
